Create a complete, enterprise-grade, production-level MOBILE APP UI/UX for an official Ganapati Mandal management platform.

IMPORTANT:
This is NOT a generic accounting app.
This is NOT a generic festival app.
This is a complete digital operating system for a Ganapati Mandal covering:
Collections, Donations, Income, Expenses, Receipts, Members, Festivals, Transactions, Pending Collections, QR/UPI Payments, Documents, Reports, Notifications, Audit History, Roles & Permissions, Administration, Security and Mandal Profile.

The application must feel like:
TRADITION + TRUST + TRANSPARENCY + SPIRITUALITY + MODERN ENTERPRISE TECHNOLOGY.

Use the OFFICIAL MANDAL LOGO PROVIDED BY THE USER as the primary brand asset.
Do not redraw, distort, recolor, stretch, crop, or replace the logo.
Use the logo consistently on splash, authentication, dashboard, receipts, profile, empty states, documents where appropriate, and branded communication screens.
